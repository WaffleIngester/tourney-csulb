# Sample Data
This folder contains sample data used to test features of the application.

## Adding Tests
One may add/ update/ remove tests as necessary.

Any significant changes **must** be documented in the corresponding README files to assure information is up-to-date.

Examples:
- Adding a new folder requires this README to be updated, in addition to any documentation which is made.
- Updating a test case changes the expected output requires one to update the subfolder's corresponding README.
  - Main `samples/README.md` (this one) only needs to be changed if necessary. Ex: now all tests are solos instead of squads.  

## Sub Folders
